# Jaiylym — пастбища села по спутнику

**Сайт:** https://ainara001.github.io/jaiylym/  ·  **Бот для пастуха:** [@JAIYLYM_bot](https://t.me/JAIYLYM_bot)

Jaiylym помогает селу распределить скот по пастбищам так, чтобы ни один участок не был перегружен,
и показывает акимату, где новый водопой откроет больше всего корма. Проект для SPARK Startup Hackathon
(направление GreenTech & Sustainability).

## Как пользоваться

**Сайт (для акимата):** найдите своё село или город в поиске либо нажмите «📍 На карте» и выберите точку.
Сайт сам загрузит снимки Sentinel-2 за последнее лето (≈10 секунд) и покажет:
- **Сейчас**: нагрузку, если все стада пасутся у села;
- **План Jaiylym**: распределение стад по участкам с водой, нигде не больше 100 %;
- **Трава (NDVI)**: реальный слой растительности со спутника;
- **Водопой**: какой дальний участок откроет больше всего корма, если поставить там воду.

**Бот (для пастуха):** `/start` → название села или геолокация → «500 овец 30 коров».
Дальше кнопки «Сегодня», «План», «Карта села», «Водопой», «📍 Где я?». На другие вопросы отвечает Gemini по данным села.

## Как это работает

| Файл | Что делает |
|---|---|
| `web/pipeline.js` | Ищет место (OpenStreetMap), снимки Sentinel-2 и карту ESA WorldCover (Microsoft Planetary Computer), считает NDVI и пастбища на 16 участках. Работает в браузере и в боте, без ключей |
| `web/engine.js` | Алгоритм: корм → ёмкость → нагрузка → план → водопои |
| `web/index.html` | Сайт |
| `bot.js` | Telegram-бот |
| `ndvi.py` | То же, что `pipeline.js`, на Python, с бо́льшим разрешением (20 м) и сравнением с 2019 годом. Им посчитан Кеген |
| `report.js` | Текстовый отчёт по селу |

Формулы (без нейросетей, всё проверяется вручную):
- Биомасса, кг/га = (NDVI − 0.10) × 4000. **Коэффициент нужно откалибровать укосом**: срезать траву с 1 м² на 3–5 участках, высушить, взвесить.
- Доступный корм = пастбище, га × биомасса × 0.5 («съел половину — оставь половину»).
- 1 условная голова (УГ) съедает ≈ 11 кг сухого корма в сутки. КРС = 1 УГ, лошадь = 1, овца/коза = 0.2.
- План: дойные стада только на ближних участках; отары сначала на дальние участки с водой; нигде не больше 100 %.

## Запуск у себя

```bash
python3 -m http.server 8765 --directory web          # сайт → http://localhost:8765
```

Бот: создайте файл `.env` (он не попадает в git):
```
TELEGRAM_TOKEN=токен_от_BotFather
GEMINI_API_KEY=ключ_из_Google_AI_Studio   # необязательно
```
```bash
node bot.js            # нужен Node 20+
node bot.js --test     # проверка без Telegram
```

## Бот круглосуточно: Render (бесплатно)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Ainara001/jaiylym)

`render.yaml` создаёт два сервиса во Франкфурте:
- **jaiylym-bot**: веб-сервис. Бот работает через webhook: Telegram сам присылает сообщения и будит сервер;
- **jaiylym-state**: Key Value (Redis), где хранятся выбранные сёла и стада, чтобы они не пропадали, когда сервер засыпает.

При создании Render попросит вставить `TELEGRAM_TOKEN` и (по желанию) `GEMINI_API_KEY`.
Бесплатный сервер засыпает через 15 минут тишины, поэтому **первый ответ после паузы приходит через ~1 минуту**.
Перед показом жюри откройте https://jaiylym-bot.onrender.com/health, чтобы разбудить бота заранее.

⚠️ Пока бот работает на Render, не запускайте `node bot.js` на своём компьютере: локальный запуск
отключает webhook, и сообщения перестанут доходить до Render. Если всё-таки запустили, перезапустите
сервис на Render (Manual Deploy → Restart), и он вернёт webhook.

## Что реальное, а что условное

**Реальное:** NDVI по снимкам Sentinel-2, маска пастбищ ESA WorldCover, площади пастбищ, поиск сёл.

**Условное:** границы участков (секторы; в реальности — схема пастбищ акимата), демо-стада в Кегене,
вода на дальних участках (по водоёмам на карте), коэффициент биомассы, цена сена (30 000 ₸/т — пример).

**Кеген, 2019 → 2026:** NDVI на ближних участках почти не изменился (−0.01), на дальних вырос (+0.03).
Это похоже на перевыпас у села, но двух лет мало для вывода: нужен ряд за 5–8 лет и проверка на месте.
