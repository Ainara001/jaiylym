# Проверки работающей системы

Что проверяется автоматически на настоящих сервисах (GitHub Actions, где есть интернет), и что могут проверить только люди.
Результаты последнего запуска — во вкладке Actions репозитория.

| Что | Как проверяется | Кто |
|---|---|---|
| Ежедневная проверка снимков | `daily-check.yml`: будит Render, вызывает `/cron` по OIDC-токену GitHub; без пароля | автоматически, каждый день 09:00 по Алматы; вручную — Actions → «Ежедневная проверка участков» → Run workflow |
| Сайт на GitHub Pages | `live-check.yml`: страница открывается, подключена модель 2.0.0, библиотека PDF на месте | автоматически по понедельникам и вручную |
| Сервер на Render | `live-check.yml`: `/health` (видна версия модели и коммит сборки), `/api/village`, `/cron` без доступа закрыт | то же |
| ИИ с настоящим ключом | `live-check.yml`: вопрос «Откуда 313 овец на Б-С?» (с вычетом жилья и ферм), сводка на казахском, вопрос без данных села; ответы печатаются в журнал | то же; качество ответа читает человек |
| Реальные снимки Sentinel-2 | `tests.yml` → `npm run test:net` | автоматически на каждом PR |
| PDF на телефоне | `tests.yml` → e2e в WebKit (движок Safari, профиль iPhone 13) и Chromium: нажатие «PDF-отчёт», скачивается настоящий PDF | автоматически на каждом PR |
| PDF на настоящем iPhone и Android | открыть сайт → Карта → «PDF-отчёт» → файл открывается, текст не обрезан, таблицы на месте | человек, один раз после выпуска |
| Бот в Telegram | `/start` → «Кеген» → «500 овец 20 коров» → «План» (первая строка — статус плана) → «Водопой» | человек |
| Казахский перевод | `docs/KK_REVIEW.md` — 700+ строк «рус ↔ каз», сначала новые строки версии 2.0 | **носитель языка** (не автоматизируется) |
| Ёмкость пастбищ | укос 1 м² на 3–5 участках, ввод коэффициента в «Настройки → Полевая калибровка» | агроном / команда в поле |
