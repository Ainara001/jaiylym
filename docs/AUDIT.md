# Аудит JAIYLYM (этап 1) и что исправлено

Проверено: ветка `main`, HEAD `5f01b1ef783483ac08eb2250165d48b347d59ba0` (на момент работы новых коммитов в `main` не было).
Изменения — в ветке `feature/spark-feedback-transparency`.

**Что проверено вживую, а что нет.** Из среды, где делалась работа, закрыт доступ к `github.io`, `onrender.com`,
Planetary Computer, OpenStreetMap, Telegram и Google. Поэтому **сайт на GitHub Pages, бот в Telegram, сервер на Render,
реальные снимки Sentinel-2 и модели Gemini в этой работе не проверялись.** Всё остальное проверено локально:
модульными тестами, сервером API на локальном порту с имитацией webhook Telegram и сайтом в Chromium (Playwright)
с подменёнными внешними запросами.
